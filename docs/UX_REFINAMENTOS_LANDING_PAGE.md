# Refinamentos de UX a partir da landing page institucional

A landing page enfatiza **preservação da família**, **proteção patrimonial** e **construção de legado**. No Wealth OS, essas mensagens são adaptadas para uma experiência operacional e reservada: a página inicial comunica governança patrimonial, o fluxo de família posiciona o projeto como núcleo da jornada e os módulos apresentam documentos, patrimônio e estruturas societárias como partes de uma arquitetura única.[1]

| Elemento observado | Aplicação no Wealth OS |
|---|---|
| Hero institucional em azul profundo | Cabeçalhos de contexto e estados seguros no dashboard e no workspace familiar |
| Linguagem de legado e proteção | Microcopy de governança, confidencialidade e preservação de informações |
| CTA de diagnóstico | CTA operacional para criar família e iniciar o projeto patrimonial |
| Imagens e traços institucionais | Uso controlado da marca oficial e geometria discreta, sem competir com os dados |

[1]: https://lucathiconsult.com.br/ "Lucathi Consult — Consultoria Patrimonial"
